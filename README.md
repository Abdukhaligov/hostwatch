# hostwatch

Панель здоровья Windows-компьютеров в локальной сети. На каждом ПК работает
маленький агент, раз в секунду он отправляет данные на сервер, а сервер
показывает их в браузере.

**Что видно по каждому ПК:** метка, имя, пользователь, IP и MAC, CPU, память,
диски, сетевой трафик, аптайм и статус:
- **ACTIVE** — за компьютером работают;
- **IDLE** — 2 минуты без мыши и клавиатуры;
- **OFFLINE** — 30 секунд нет отчётов.

Компьютеры с проблемами (CPU ≥90% дольше 2 минут, память ≥90%, на диске
меньше 10% свободного) показываются первыми. На вкладке **IDLE** видно,
сколько каждый ПК был активен и сколько простаивал за день (история за неделю).

## Сервер

Нужен Python 3.9+ или Docker. Подойдёт любая машина в сети.

```bash
python3 -m venv .venv
.venv/bin/pip install -r server/requirements.txt
cd server
../.venv/bin/uvicorn app:app --host 0.0.0.0 --port 8765
```

Или через Docker: `docker compose up -d --build`.

Панель: `http://<IP сервера>:8765`. Данные хранятся в `server/data/` (или в
`data/` при запуске через Docker).

Если сервер на Windows, открой порт (один раз, от администратора):

```
netsh advfirewall firewall add rule name=hostwatch dir=in action=allow protocol=TCP localport=8765
```

Настройки через переменные окружения: `HOSTWATCH_IDLE_AFTER` (120 с),
`HOSTWATCH_STALE_AFTER` (30 с).

## Агент (на каждом Windows-компьютере)

1. Открой панель в браузере на этом компьютере.
2. Нажми **⬇ INSTALL AGENT** и запусти скачанный `install.cmd`.

Права администратора не нужны, адрес сервера уже вписан в файл. Агент
запускается вместе с Windows и работает в фоне с точкой в трее (голубая — всё
хорошо, красная — нет связи с сервером). Меню иконки: **Set label…**,
**Open dashboard**, **Change server…**, **Exit**. Метку можно поменять и в
панели (✎).

![Меню в трее](docs/tray.png)

Первая строка меню — метка и последний статус отправки (здесь сервер был
недоступен).

Удаление: `agent/uninstall.cmd`.

Нужна Windows 10/11 (PowerShell 5.1 встроен).

## Демо

Чтобы посмотреть панель без настоящих агентов (или сделать скриншоты):

```bash
cd server
HOSTWATCH_DEMO=1 ../.venv/bin/uvicorn app:app --port 8765
```

Запустится выдуманный офис из 8 компьютеров с историей за неделю. В демо-режиме
ничего не сохраняется, настоящие данные не затрагиваются.
